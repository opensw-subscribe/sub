## 🔧 프로젝트 안내사항

이 프로젝트는 **Firebase**를 사용합니다.

Firebase 프로젝트에서 앱을 생성한 후 아래 두 파일을 다운로드해야 합니다:

- **google-services.json**
- **비공개 키(Python).json**

다운로드 후 아래와 같이 파일을 배치해 주세요:
* Frontend/android/app/google-services.json
* Backend/service_account_key.json ← 비공개 키(Python).json 이름 변경

각 실행 과정은 해당 폴더의 README.md를 참고해주세요.
- **Frontend 실행 방법:** [Frontend/README.md](./Frontend/README.md)
